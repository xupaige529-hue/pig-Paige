# 数智统计实验室（原型）

## 项目目标
面向大学低年级统计学/概率论学习者，提供概率分布参数交互、抽样分布模拟、推断统计演示、概念自测与分步提示。

## 当前版本包含
1. 概率分布实验室：正态、二项、泊松、均匀、指数、t、卡方共 7 种分布的参数交互，附区间概率计算器，图表可导出 PNG。
2. 抽样与中心极限定理：支持 5 种总体（指数/均匀/正态/对数正态/双峰）反复抽样，观察样本均值分布与标准误随样本量的衰减，可导出抽样数据 CSV。
3. 大数定律演示：样本均值随样本量增大收敛于总体均值。
4. 置信区间模拟：重复抽样构造置信区间，验证覆盖率接近名义置信水平。
5. 假设检验 z 检验：已知总体标准差 σ 时检验样本均值是否显著偏离原假设，可视化拒绝域、临界值与 p 值。
6. 自测题与本地分步提示：6 道概念题即时判分 + AI 助教提示词生成（本版本无内置大语言模型 API，不会自动发送用户问题）。
7. 中文字体自动处理：优先使用系统字体；云端无中文字体时自动联网下载并注册（Noto Sans SC / SimHei），图表中文不再显示为方框；也可手动上传字体文件 `cjk_font.otf` / `cjk_font.ttf` 到项目目录。
8. 校徽容错：缺少 `nenu_logo.jpg` 时页面自动降级，不影响运行。
9. 界面无表情符号，风格统一；模拟计算全部使用缓存，降低云端算力开销。

## 环境要求
建议 Python 3.10 或更新版本。

## 本地运行
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```
运行后，按终端提示在浏览器打开本地地址。

## 部署到 Streamlit Community Cloud
1. 将 `app.py`、`requirements.txt` 上传到 GitHub 公共仓库（或直接在 Streamlit 编辑器中替换 `app.py` 内容）。
2. 如需显示校徽，将 `nenu_logo.jpg` 一并上传；不上传也不影响运行。
3. 首次运行会自动下载中文字体（约 10~20 MB，仅首次需要），此后缓存在项目目录中。
